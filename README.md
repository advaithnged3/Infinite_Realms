# Infinite Realms

A cinematic Marvel/DC-inspired trivia experience prototype.

## Stack
- Next.js App Router
- React
- TypeScript
- CSS

## Run locally
```bash
npm install
npm run dev
```

## Prototype status
This first version is a front-end prototype. It includes universe selection, a seven-question typed-answer demo, rarity scoring, destination reveals, and local demo leaderboard/archive views. Demo answers and scores are client-side and are **not suitable for a public competitive launch**.

Before launch, move question answers and scoring to a server-side API, add persistent storage and authentication, implement daily quiz scheduling, rate limits, anti-cheat controls, and moderation/admin tools.

## Deployment
Import this repository into Vercel and deploy with the default Next.js settings.
